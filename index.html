NOAA predictions — San Diego Bay (station 9410170)

Loading tides…
Click anywhere on the chart to check the tide at that moment
Harmonic tide predictions straight from NOAA CO-OPS (no relay needed — that API allows direct browser requests) — height is relative to MLLW (Mean Lower Low Water), the standard nautical charting datum. A prediction, not a live gauge reading, but tides are governed by orbital mechanics rather than weather, so unlike the rest of this chart's live layers this one is exact arbitrarily far into the future.

Real-time observed readings from a NOAA/Scripps waverider buoy ~20 miles off Point Loma — a buoy measures, it doesn't forecast, so this always shows the latest actual reading regardless of which tide day is selected above. Unlike the tide data, NDBC doesn't send its own CORS header, so this routes through the same relay service as the currents/fish-count layers elsewhere in this chart.

Loading forecast…
Open-Meteo's marine & weather forecast models, for the same Point Loma South buoy location as the observed swell above — unlike that buoy reading, this one does project days ahead. Each day's "Good/Fair/Rough" tag is a rough small-boat comfort guide (wind & wave thresholds only, not a safety forecast) — always check the NWS marine forecast and any small craft advisories before running offshore.
